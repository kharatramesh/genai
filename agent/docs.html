Agent Frameworks Guide

Three terminal agents (no FastAPI), each built with a different framework and all driven by a local Ollama model.

Prerequisites

  • Python 3.10+
  • Ollama running on http://localhost:11434 with the model pulled: ollama pull qwen3:8b
  • Packages: 
    pip install langchain langchain-ollama langgraph crewai

1. LangChain — langchain_agent/agent.py

Tools are plain Python functions decorated with @tool. create_agent wires the model and tools into a ready-made agent loop; you only call invoke.

llm = ChatOllama(model="qwen3:8b", base_url="http://localhost:11434")
agent = create_agent(llm, tools=[create_file, read_file, list_files])
result = agent.invoke({"messages": [{"role": "user", "content": question}]})

Run:

python langchain_agent/agent.py

Files are written to langchain_agent/workspace/. Press Enter on a blank line to quit.

2. LangGraph — langgraph_agent/agent.py

The same tools, but the control flow is explicit. State is a list of messages; the graph loops between the model and the tool executor until the model replies without a tool call.

START → model → (tool call?) → tools → model → ... → END
graph = StateGraph(MessagesState)
graph.add_node("model", call_model)
graph.add_node("tools", ToolNode(tools))
graph.add_edge(START, "model")
graph.add_conditional_edges("model", tools_condition)
graph.add_edge("tools", "model")
app = graph.compile()

Run:

python langgraph_agent/agent.py

Files are written to langgraph_agent/workspace/. Choose LangGraph over create_agent when you need custom branching, human approval steps or persistent state.

3. CrewAI — crewai_agent/agent.py

Two agents with distinct roles collaborate through tasks. The writer's task takes the researcher's output as context. The crew runs sequentially.

llm = LLM(model="ollama/qwen3:8b", base_url="http://localhost:11434")
crew = Crew(agents=[researcher, writer],
            tasks=[research_task, write_task],
            process=Process.sequential)
crew.kickoff(inputs={"topic": topic})

Run (topic is optional, default "agentic AI"):

python crewai_agent/agent.py "the Python language"

On Windows the script forces UTF-8 on stdout/stderr, because CrewAI prints emoji that the default cp1252 console cannot encode.

Troubleshooting

SymptomFix
Connection refused on port 11434Start Ollama (ollama serve).
Model not foundollama pull qwen3:8b, or change the model name in the script.
charmap codec errorsSet PYTHONUTF8=1 or keep the reconfigure lines in the CrewAI script.
Slow repliesLocal 8B models are slow on CPU; use a smaller model such as llama3.2.
Tool never calledUse a model that supports tool calling; small models may ignore tools.
